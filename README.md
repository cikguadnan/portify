# Portify

A student-first portfolio builder that makes it easy to create a polished personal website without learning web design.

## Version 1

- Editable student profile
- Live website preview
- Experience / CCA / VIA / leadership / project entries
- Three visual themes
- Portfolio completion indicator
- Publish/share prototype
- Responsive mobile layout
- Local browser persistence (no backend yet)

## Run

Open `index.html` locally, or enable GitHub Pages from the repository's main branch.

## Next phase

Authentication, cloud data/storage, teacher classes/dashboard, permanent public student URLs, image uploads, feedback, résumé generation and AI-assisted reflections.
